🏨 BookMyStay - Hotel Booking & Reservation Website

BookMyStay is a Full Stack Hotel Booking and Reservation Management System that allows users to search hotels, book rooms, and manage reservations. Hotel owners can manage hotels, rooms, bookings, and view dashboard analytics.


# ✨ Features

## 👤 User Module

- User Registration
- User Login (JWT Authentication)
- Update Profile
- Search Hotels
- View Hotel Details
- Book Hotel Rooms
- View Booking History
- User Dashboard
- Logout

---

## 🏨 Hotel Owner Module

- Owner Registration
- Owner Login
- Owner Profile
- Add Hotel
- Edit Hotel

- Add Rooms

- View Reservations

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/payalrajput09/Hotel-Booking-and-Reservation-Website.git
```

## Go to Backend Folder

```bash
cd backend
```

## Install Dependencies

```bash
npm install
```

## Create .env File

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

## Run Backend
```bash
npm run dev
```

## Open Frontend
Simply open
```
index.html
```
using Live Server.
---



# 🔐 Environment Variables
